# Hangman Game 🎮

A simple Hangman game implemented in Python.

This project contains two implementations of the same game:

- Procedural / Functional version
- Object-Oriented Programming (OOP) version

## Game Rules

- The secret word is randomly selected from a list.
- The player has 5 wrong guesses.
- Repeated guesses do not count as an error.
- English words are used.
- The player can replay the game.

## Concepts Practiced

- Python functions
- Lists
- Loops
- Conditions
- Random module
- Input validation
- Object-Oriented Programming
- Classes and objects
- Encapsulation
